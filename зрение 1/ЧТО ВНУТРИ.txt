  ЗРЕНИЕ 1 — ИИ-система «что и где» на экране Genshin Impact
════════════════════════════════════════════════════════════════

Полный рабочий проект: понимание экрана игры в реальном времени.
Всё уже протестировано (18/18 тестов) и работает без обучения модели
(эвристика) и с обученной YOLO (опционально).

──────────────────────────────────────────────────────────────────
ЧТО СИСТЕМА ПОНИМАЕТ
──────────────────────────────────────────────────────────────────
• Игрок: HP (текущее/макс.), стамина, готовность ульт, полоска босса
• Враги (все типы): слизни, хиличурлы, митачурлы, руинные машины,
  маги Бездны, боссы... — тип (slime/hilichurl/ruin_guard/...),
  уровень (enemy/elite/boss), стихия (pyro/hydro/electro/...)
• Враги БЕЗ полосок HP: слизни и стихийные тела по цвету (enemy_rules)
• Угроза каждого врага: aggro (заметил), threat (высокая/средняя/низкая)
  по дистанции и скорости сближения с игроком; сводка enemies_summary
• Сундуки по статусу: chest_unlocked (без кольца → «подойди и нажми F»)
  / chest_locked (красное кольцо → «сначала враги или головоломка»)
• Телепорты/статуи по цвету: teleport_inactive (красный → активировать)
  / teleport_active (голубой → игнорировать, уже открыт)
• Момент взаимодействия ui_interact_f: иконка клавиши F с текстом
  («Обычный сундук», «Подобрать») → сигнал «остановиться и нажать F»
• Миникарта: курс игрока (0° = север), иконки телепортов/статуй/квестов,
  движение (фазовая корреляция)
• Объекты мира: кукулиусы (подношения семи архонтам) с стихиями,
  головоломки — с расстоянием в метрах
• Общий сигнал боту action_hint: stop_and_press_f → fight → approach
  → explore (у каждого объекта — свой action)

──────────────────────────────────────────────────────────────────
КАК ЗАПУСТИТЬ
──────────────────────────────────────────────────────────────────
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# демо без игры (синтетическая сцена) → браузер на http://localhost:8000
.venv/bin/python scripts/run_demo.py --port 8000

# реальная игра (захват экрана)
.venv/bin/python scripts/run_live.py --calib config/default_calibration.json

# оффлайн по видео
.venv/bin/python scripts/run_video.py video.mp4 --out out/

# калибровка HUD под свой интерфейс
.venv/bin/python -m genshinvision.calibrate

# тесты: 18 штук, включая сверку с ground truth
.venv/bin/python -m pytest tests/ -q

# обучение YOLO (опционально, нужен pip install -r requirements-ml.txt)
# классы и советы по разметке: training/README.md, training/dataset.yaml

──────────────────────────────────────────────────────────────────
КАТАЛОГИ
──────────────────────────────────────────────────────────────────
genshinvision/   ядро: захват, детектор (эвристика + YOLO), HUD,
                 миникарта, трекер (Kalman), состояние (JSON), стрим
overlay/         живой оверлей в браузере (WebSocket ~20 Гц)
scripts/         демо/живой запуск/видео/запись геймплея
tests/           18 тестов (тесты сверяют работу с эталонной сценой)
training/        как обучить свою YOLO: классы, разметка, экспорт
config/          калибровка HUD по умолчанию (HSV-правила объектов)
out/             готовые примеры: аннотированные кадры и видео

──────────────────────────────────────────────────────────────────
ФОРМАТ СОСТОЯНИЯ (WebSocket /ws, GET /state)
──────────────────────────────────────────────────────────────────
player, enemies (+ enemy_type/element/aggro/threat/distance_m),
enemies_summary, interactables (+ action: press_f/ignore/search_area),
ui (+ interact_f — момент нажатия F), action_hint, minimap, fps...
Полное описание и пример JSON — в README.md (раздел «Формат состояния»).
