# Примеры кадров

Скриншоты Genshin Impact из открытых публикаций (превью гайдов), используются
только как тестовый материал для проверки восприятия. Не являются ассетами игры
и не распространяются как часть проекта.

Проверить на них агента:

```bash
python -m parkour demo examples/screens/*.jpg examples/screens/*.png --out out/demo
```
